# Mock Final Presentation — FXGCF built **bottom-up (GDP-weighted)**

A *mock* of the final presentation in which the FX-adjusted global cycle factor
(FXGCF) is rebuilt **bottom-up**: a local USD cycle factor is estimated per
country and GDP-weighted into the global factor — i.e. the exact GCF recipe with
the US-dollar return on the left-hand side, instead of the current top-down
fit on GDP-weighted aggregates. Everything else matches `final_presentation/`.

This deck exists to show how the final-presentation story changes under the
alternative construction the supervisor asked about (see `../fxgcf_comparison/`).

## What changes vs. the baseline deck

Only the FXGCF-dependent exhibits and their narrative differ; all
FXGCF-independent slides (Phase I, Phase II, data, OOS local/global, hedged
strategy) are unchanged.

| | Baseline (top-down GDP) | This deck (bottom-up GDP) |
|---|---|---|
| cor(FXGCF, GCF) | 0.99 | **0.78** |
| mean USD-investor IS R² | 0.095 | **0.143** (8%→14%) |
| FXGCF R² > GCF R² | 10/11 | 10/11 |
| pooled OOS R² (rx_USD ~ FXGCF) | +0.002 | **+0.019** (6/11) |
| USD timing strategy | Sharpe 0.20→0.24, R²_oos 0.12 | Sharpe 0.20→**0.19**, R²_oos **−0.01** |

**Takeaway:** the bottom-up factor is far less collinear with the GCF and the
best *cross-sectional* predictor, but as a single global-portfolio timing signal
it underperforms, and out of sample it is fragile across estimation schemes.

## Regenerate

The FXGCF-sensitive exhibits are produced by the shared generator (run from the
repository root), which sources the real pipeline under `FXGCF_METHOD=bu_gdp`:

```sh
FXGCF_METHOD=bu_gdp Rscript tools/build_variant_presentation.R   # -> figures/ + tables/
cd final_presentation_bu_gdp && latexmk -pdf main.tex
```

Regenerated by the generator: `figures/{mr_f3_usd_r2,mr_f4_gcf_fxgcf,rob_f1_oos_sub,rob_f2_oos_scheme}.pdf`
and `tables/{mr_t3_phase3,mr_t4_oos}.tex`. All other exhibits are inherited from
`final_presentation/`. The compiled `main.pdf` and LaTeX logs are git-ignored.
