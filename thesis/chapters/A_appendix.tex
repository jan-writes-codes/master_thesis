\section{AI Disclaimer}
\label{app:ai}
% Honest account of the AI-assisted tools used in this work. Keep this
% consistent with the "Statement on the use of generative AI tools" in the
% Declaration of Authorship.

The following AI-assisted language and coding models were used in the
preparation of this work: Claude (Sonnet~4.6 and Opus~4.8, Anthropic),
ChatGPT Codex (Codex~5.3 and GPT~5.5, OpenAI).

Claude and ChatGPT Codex were used to support the implementation of the coding
pipeline, including code generation and debugging, validation of model outputs,
summarization of results, and the production of charts and figures.

ChatGPT Codex additionally served as the execution environment for running the
code pipeline. Claude was also used in a minor supporting capacity during the
preparation of presentation slides; however, all slides were conceived,
structured, and finalized by the human author, with AI assistance representing
a negligible share of the final content.

All AI-generated outputs were reviewed, critically assessed, and adapted by the
author. The data handling and model analysis were performed locally. Model
training and index construction were implemented via cloud computing
(Vast.ai and GCP).
