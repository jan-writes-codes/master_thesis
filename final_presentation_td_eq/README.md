# Mock Final Presentation — FXGCF built **top-down (1/n-weighted)**

A *mock* of the final presentation in which the FX-adjusted global cycle factor
(FXGCF) keeps the current **top-down** construction (fitted value of the average
USD return on the average cycle predictors) but uses **equal (1/n) weights**
across countries instead of GDP weights. Everything else matches
`final_presentation/`.

This deck exists to show how the final-presentation story changes under the
alternative construction the supervisor asked about (see `../fxgcf_comparison/`).

## What changes vs. the baseline deck

Only the FXGCF-dependent exhibits and their narrative differ; all
FXGCF-independent slides (Phase I, Phase II, data, OOS local/global, hedged
strategy) are unchanged.

| | Baseline (top-down GDP) | This deck (top-down 1/n) |
|---|---|---|
| cor(FXGCF, GCF) | 0.99 | **0.94** |
| mean USD-investor IS R² | 0.095 | **0.106** (8%→11%) |
| FXGCF R² > GCF R² | 10/11 | 9/11 |
| pooled OOS R² (rx_USD ~ FXGCF) | +0.002 | **+0.027** (8/11) |
| USD timing strategy | Sharpe 0.20→0.24, R²_oos 0.12 | Sharpe 0.20→**0.26**, R²_oos **0.13** |

**Takeaway:** equal weighting alone barely decouples the factor from the GCF
(0.99→0.94), but it is the most robust out of sample — the best pooled
Campbell–Thompson R² and the best dollar-investor timing of the constructions.

## Regenerate

The FXGCF-sensitive exhibits are produced by the shared generator (run from the
repository root), which sources the real pipeline under `FXGCF_METHOD=td_eq`:

```sh
FXGCF_METHOD=td_eq Rscript tools/build_variant_presentation.R   # -> figures/ + tables/
cd final_presentation_td_eq && latexmk -pdf main.tex
```

Regenerated by the generator: `figures/{mr_f3_usd_r2,mr_f4_gcf_fxgcf,rob_f1_oos_sub,rob_f2_oos_scheme}.pdf`
and `tables/{mr_t3_phase3,mr_t4_oos}.tex`. All other exhibits are inherited from
`final_presentation/`. The compiled `main.pdf` and LaTeX logs are git-ignored.
